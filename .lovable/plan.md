أفضل ميزة يمكن إضافتها الآن: **"طلبات العملاء" مع التوصية الذكية للعقارات**

**الفكرة**
بدل ما يكون التطبيق مجرد أرشيف للعقارات، نحوّله إلى أداة بيع حقيقية: كل موظف يسجّل طلب العميل (ميزانية، نوع العقار، المنطقة، الغرض…)، والنظام يبحث تلقائياً بين العقارات المتاحة ويقترح العروض المطابقة، ويسجّل كل متابعة.

**لماذا ترفع السعر؟**
- مكاتب العقارات تخسر صفقات لأنها تنسى متابعة الزبائن أو لا تجد العرض المناسب بسرعة.
- هذه الميزة تربط مباشرة بين التطبيق وزيادة إيرادات المكتب، فيصبح السعر "استثمار" وليس "اشتراك".
- تفتح مساحة جديدة للتسعير: يمكنك لاحقاً تقييد عدد الطلبات النشطة في كل plan.

**ما سنبنيه**
1. جدول `client_requests` في قاعدة البيانات:
   - معلومات العميل: الاسم، الهاتف، طريقة التواصل (واتساب/اتصال/زيارة).
   - متطلبات العقار: نوع الإعلان، نوع العقار، المحافظة، المنطقة، الحي، الحد الأدنى/الأقصى للسعر والمساحة، عدد الغرف، الطابق، الإكساء، المزايا المطلوبة، الواجهة.
   - حالة الطلب: جديد، قيد المتابعة، مغلق، تم التحويل لصفقة.
   - ملاحظات وتاريخ المتابعة القادم.

2. محرك مطابقة بسيط داخل `properties.functions.ts`:
   - عند إضافة/تعديل عقار، يُعاد فحص كل الطلبات النشطة ويُرجَع قائمة المطابقات.
   - عند فتح طلب، يُعرض للموظف مباشرةً العقارات المطابقة مع درجة تطابق (عالية/متوسطة/ضعيفة).

3. شاشات جديدة:
   - `/requests` — قائمة طلبات العملاء مع بحث وفلترة حسب الحالة والتاريخ.
   - `/requests/new` — إضافة طلب جديد باستخدام نموذج مشابه لنموذج العقار.
   - `/requests/$id` — تفاصيل الطلب، العقارات المطابقة، سجل المتابعات، وزر "مشاركة عبر واتساب".
   - `/requests/$id/followups` — إضافة متابعة جديدة وتحديد موعد المتابعة القادم.

4. تكامل واتساب:
   - مشاركة العقارات المطابقة للعميل كنص منسّق بزر واحد.
   - زر "اتصل/راسل العميل" يفتح `tel:` أو `wa.me`.

5. تتبع النشاط:
   - تسجيل إنشاء الطلب، تعديله، إضافة متابعة، ومطابقة عقار في `activity_logs`.

6. صلاحيات:
   - المدير والموظف يمكنهم إنشاء/تعديل الطلبات، لكن المدير فقط يحذف.
   - كل طلب مقيّد بـ `workspace_id`.

**الخطوات الفنية**
- إنشاء migration لجدول `client_requests` و `request_followups` مع `GRANT` و `RLS`.
- إنشاء دوال `request.functions.ts` للـ CRUD والمطابقة.
- تحديث `activity_logs` لإضافة `request_id` اختياري.
- إنشاء المسارات والمكونات الجديدة بنفس أسلوب "Liquid Glass" الحالي.
- تحديث شريط التنقل لإضافة "طلبات العملاء".

**المدة المقدرة**: تنفيذ كامل في جولة واحدة.

**تأثير السعر**: ميزة CRM صغيرة تضيف قيمة عالية جداً لمكاتب العقارات وتبرّر زيادة الاشتراك الشهري.
